## Getting started

This is a scaffolded Jekyll site. Edit [`index.md`](index.md) to change this
landing page, or tweak `_layouts/home.html` for the structure.

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve` and open <http://localhost:4000>.
